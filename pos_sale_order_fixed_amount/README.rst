This add‑on lets you generate a fixed‑amount down payment against
a sales order directly from the point of sale.

**Table of contents**

.. contents::
   :local:

Usage
=====

To use this feature, simply go to Sales Orders from within the Point‑of‑Sale.
Select the order, and an option will appear that lets you create a fixed‑amount down payment.
