This module extends Odoo payment method configuration to allow hiding
terminal payment information from customer receipts. It adds a simple
option on payment methods that controls whether payment details (such as
card or terminal transaction information) should be displayed on printed
or digital receipts.

Use Cases / Context
===================

In many retail environments, electronic payment terminals automatically
print or generate a payment ticket containing sensitive and detailed
transaction information (card type, authorization code, terminal ID,
etc.). By default, Odoo also prints payment details on the customer
receipt.

The business requirement behind this module is to avoid printing
redundant or sensitive terminal payment information on Odoo receipts
when the terminal already provides a dedicated payment ticket.

Configuration
=============

To configure this module, you need to:

- Go to Point of Sale > Configuration > Payment Methods
- Open a payment method
- Activate/Deactivate boolean ``Hide payment informations from receipt``
