This module allows to set the invoice salesperson as the customer one if
defined and not the POS Cashier.

That behavior is configurable per POS.

**Table of contents**

.. contents::
   :local:

Configuration
=============

- Go to Point of Sale > Configuration > Accounting
- Check the 'Use Customer Seller in Invoices' box

Usage
=====

- See CONFIGURE section for configuration.
- Set a salesperson on customer side.
- Do a POS order with customer selection and create an invoice.
