The POS *Quotation/Order* button lists the sale orders a cashier can
settle. Odoo restricts that list to orders with an amount left to pay,
and ``sale.order.amount_unpaid`` is clamped to zero, so a sale order
totalling a negative amount is never offered and the *Settle the order*
option cannot be reached.

This module lists sale orders totalling a negative amount as well, so
that a cashier can settle them and pay the customer out through the POS.
The order leaves the list once it has been settled, like any other one.

Configuration
=============

The feature is enabled by default. To change it per point of sale:

1. Go to *Point of Sale > Configuration > Settings*.
2. Select the point of sale to configure.
3. In the *Sales* section, tick or untick *Always Enable Order Settle*.

Usage
=====

1. Confirm a sale order totalling a negative amount.
2. Open a POS session and click *Quotation/Order*.
3. The order is listed; select it and choose *Settle the order*.
4. Its lines are loaded into the POS order with their negative
   quantities, and the customer is paid out on validation.
