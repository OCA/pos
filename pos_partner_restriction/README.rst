=========================
POS - Partner Restriction
=========================

This module allows you to restrict which partners are loaded and selectable in
the Point of Sale (POS).

Only partners with the boolean field
*Allowed in POS (Pay on account)* will be loaded into the POS frontend.

**Table of contents**

.. contents::
   :local:

Usage
=====

Once configured, start a new POS session.

Only partners with **Allowed in POS (Pay on account)** enabled will be
available for selection in the POS frontend.

Known issues / Roadmap
======================

This module restricts which partners are loaded into the Point of Sale (POS).
Only partners explicitly marked as allowed are sent to the POS frontend,
but in the future we can setup the POS itself to accept/reject partners
