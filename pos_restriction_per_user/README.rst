The module allows you to restrict access to each point of sale to only
the specified users.

Users with the Point of Sale > Administrator permission can view all
points of sale data.

**Table of contents**

.. contents::
   :local:

Usage
=====

Go to Point of Sale > Settings, and in the "Restriction" section,
specify the users.
