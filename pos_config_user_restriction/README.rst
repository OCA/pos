Restricts Point of Sale users and managers to specific POS
configurations:

- Adds *Allowed Points of Sale* on ``res.users`` (empty means
  unrestricted access).
- Enforces record rules across POS configs, sessions, orders, order
  lines, payments, and POS order analysis reports.
- Optional *Hide POS Configuration Menus* toggle to hide POS
  configuration menus for non-admin restricted users.

Usage
=====

1. Go to *Settings > Users* and open a POS user or manager.
2. Under *Access Rights > Point of Sale Access*, select one or more
   *Allowed Points of Sale*.
3. Optionally keep *Hide POS Configuration Menus* enabled to hide
   configuration menus for that user while retaining cashier and session
   closing capabilities.
