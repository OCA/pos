This module adds RMA management directly within the Point of Sale (POS)
interface. Users can create RMAs from order lines, with validations on
return quantity and a required reason. It links RMAs to POS orders for
easy tracking.

Usage
=====

How to Use
----------

1. Go to **Point of Sale**.
2. Open a session in the POS.
3. Go to **Orders** and select an order.
4. Click on an order line and then click the **Create RMA** button.
5. If an RMA can be created for this product, a popup will appear asking
   you to enter the quantity and reason.
6. The popup validates the quantity and requires a reason.
7. Once confirmed, a new RMA is created and a success message is
   displayed.

You can also consult RMAs linked to each order from the order details in
backend.
