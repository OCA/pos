This module blocks the POS if a product is scanned with a barcode that
doesn't exist in Odoo.

**Table of contents**

.. contents::
   :local:

Configuration
=============

- Select a product or create a new one
- On the barcode field set the reference you want

Usage
=====

- Open a POS session
- With a barcode generator tool, write a reference that isn't set on any
  of your products
- An error modal screen will appear
