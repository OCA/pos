In Odoo 18 the PoS always sets the expiration date of the gift cards it
generates to today plus one year, so the fixed duration provided by
*Loyalty Card Fixed Expiration Date*
(``loyalty_card_fixed_expiration_date``) has no effect on gift cards
sold in the PoS, because they already come with an expiration date.

This module makes the PoS use the **Duration Days** of the gift card
program instead.

Usage
=====

Follow these steps to configure and use the module:

1. Go to **Point of Sale -> Products -> Gift cards & eWallet**.
2. Open (or create) a program with **Program Type** set to **Gift Card**
   and set the **Duration Days**.
3. Sell a gift card in the PoS: the generated card expires on the sale
   date plus the duration of the program.
4. When creating a gift card manually from the order summary, the
   expiration date is proposed with that same duration and can be
   changed by the cashier.

If the program has no duration (0), the standard Odoo behavior is kept
(one year).
