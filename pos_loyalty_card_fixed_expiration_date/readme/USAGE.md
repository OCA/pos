Follow these steps to configure and use the module:

1. Go to **Point of Sale -> Products -> Gift cards & eWallet**.
2. Open (or create) a program with **Program Type** set to **Gift Card** and
   set the **Duration Days**.
3. Sell a gift card in the PoS: the generated card expires on the sale date
   plus the duration of the program.
4. When creating a gift card manually from the order summary, the
   expiration date is proposed with that same duration and can be changed by
   the cashier.

If the program has no duration (0), the standard Odoo behavior is kept
(one year).
