This module extends the functionality of the pos_order_to_sale_order module
by allowing you to create sales orders specifying a commitment date from
the Point of Sale.

**Table of contents**

.. contents::
   :local:

Configuration
=============

Select PoS > Configuration > Settings > Point of sale > enable flag "Allow Commitment Date":


Usage
=====

After enabling the option mentioned in the configuration section, go to the Point of Sale.
Once inside, create an order just like with the ``pos_order_to_sale_order`` add-on,
and use the option to create a sale order.

.. figure:: https://raw.githubusercontent.com/OCA/pos/16.0/pos_order_to_sale_order_commitment_date/static/description/img/1.png

Once the popup appears, there is an option called **"Add Commitment Date"**.
If you select it and click on any of the base options,
a new popup will appear allowing you to add the delivery date.
.. figure:: https://raw.githubusercontent.com/OCA/pos/16.0/pos_order_to_sale_order_commitment_date/static/description/img/2.png
