Description
===========

This module extends the **Odoo Point of Sale (POS)** order management
screen by adding a **datepicker filter**.

**Features:**

- Adds a **datepicker widget** next to the POS order filter bar.
- Allows users to filter orders by **exact date**.
- Works seamlessly with other POS filters.
- Prevents selecting **future dates**.
- Fully integrated in **Odoo 18 POS** UI.

Use Cases / Context
===================

Use Cases / Context
===================

| This module was created to help POS users quickly find orders by date.
| Instead of scrolling through all orders or relying only on
  customer/cashier filters,
| they can now narrow down results with a **date filter**.

Typical scenarios:

- Reviewing daily sales.
- Validating specific date transactions.
- Auditing POS operations.

Configure
=========

Usage
=====

Usage
=====

1. Go to **Point of Sale → Orders**.
2. Use the search bar and filters as usual.
3. Select a **date from the datepicker** to view only the orders from
   that date.

Known issues / Roadmap
======================

Known Issues / Roadmap
======================

At the moment:

- Future dates are disabled intentionally.
- No support yet for filtering by date ranges (only exact date).

Planned improvements:

- Add **date range filter** (From / To).
- Improve performance for large order datasets.
