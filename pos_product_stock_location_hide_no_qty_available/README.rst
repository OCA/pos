The goal of this module is to restrict the visibility of products that
are not available in selected warehouses during the opening of the PoS.

.. contents::
   :local:

Usage
=====

To use this module, you need to:

-  Go to *Point Of Sale* > Configuration
-  Activate boolean \*Only display products which are available in the
   default source location of the picking type. on the wanted point of
   sales
-  Default source location of the linked picking type will be used
-  Select additional locations if needed
-  Save

When opening a point of sales, stockable products which are not
available in relevant locations won't be displayed. If a products become
unavailable after the point of sales has been opened, it won't be
removed.
